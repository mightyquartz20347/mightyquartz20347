# Hey, I'm mightyquartz20347

I spend most of my time writing Python scripts that make repetitive work disappear. Whether it's batch processing files, scheduling tasks, or connecting different services through simple APIs, automation is the part of coding I enjoy most.

## What I focus on

### Python & everyday automation
Python is my go-to language because it lets me move quickly from idea to working tool. I write scripts for data cleanup, monitoring local systems, and stitching together small pipelines that run without constant attention. Clean, readable code matters more to me than clever one-liners.

### Linux as a daily driver
I prefer working in a terminal. Most of my environment lives on Linux machines where I can control packages, services, and permissions without layers of abstraction getting in the way. Understanding how the OS actually works helps me debug faster when something inevitably breaks at 2 a.m.

### Cloud basics
I use cloud platforms to host small services and store data that needs to stay available. Nothing fancy—mostly object storage, lightweight compute instances, and simple networking. The goal is always reliability over complexity.

## A bit about how I work

I like keeping things modular. A script should do one job well and be easy to extend later. Documentation is part of the code, not an afterthought. When I open a project months later I want to understand it without reverse-engineering my own decisions.

Outside of pure coding I enjoy reading about system design patterns and experimenting with different ways to structure automation workflows. The best tools are the ones that stay out of the way once they are set up.

Feel free to look around the repositories. Most of them are practical experiments rather than polished products. If something looks useful, fork it and make it better.
